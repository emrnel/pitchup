A video-first mobile platform connecting startups with investors. Built with Flutter & Firebase.

## Features

- 📹 Video pitch recording and upload
- 💼 Investor-startup matching
- 🔔 Real-time notifications
- 👤 User profiles and portfolios

## Tech Stack

`Flutter` `Firebase` `Dart` `Cloud Functions`
